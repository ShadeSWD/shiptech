Обработка труб судовых систем

На судне — десятки километров трубопроводов, и почти каждая труба гнётся по месту под свою трассу. Сквозной пример: стальная труба Ø180×7 мм из легированной стали 12Х1, радиус гиба \(R_{\text{у}} = 500\) мм, четыре типовые конфигурации (вариант 15).

Цель работы

Разработать технологический процесс обработки труб судовых систем: определить длины заготовок для четырёх типов труб, назначить режимы гибки с нагревом ТВЧ (скорости, температуры, дорн), проверить качество гиба (утонение, гофры, овальность, пружинение) и рассчитать нормы времени на обработку партии из 10 труб с приварными фланцами.

Теория вопроса

Трубопроводы судовых систем (балластной, осушительной, топливной, охлаждения) собирают из отдельных труб с фланцевыми соединениями, и каждая труба проходит один и тот же цех: отрезка заготовки → гибка → обработка концов → приварка фланцев → гидравлические испытания → маркировка. Заготовку нельзя отрезать «по чертёжной длине» участков: на каждом гибе труба идёт по дуге нейтральной линии, поэтому длину заготовки считают как сумму прямых участков плюс развёртки дуг, плюс технологический припуск.

Гибку труб такого диаметра ведут с нагревом токами высокой частоты (ТВЧ): узкая кольцевая зона трубы разогревается индуктором до 850–960 °C и изгибается на роликовом станке; изнутри трубу поддерживает дорн, не дающий сечению сплющиться. Качество гиба контролируют тремя показателями: утонением стенки на наружной образующей, высотой гофров на внутренней и овальностью сечения. Из-за упругого пружинения трубу перегибают на 2–4° сверх заданного угла.

Завершает процесс нормирование: штучно-калькуляционное время каждой из 12 операций складывается в норму на трубу, а нормы — в трудоёмкость партии. Именно так планируется загрузка трубообрабатывающего цеха верфи.

Четыре типовые конфигурации трубы Ø180×7: прямая, Г-образная с одним гибом 90° радиусом \(R_{\text{у}} = 500\) мм, труба с двумя гибами 90° во взаимно перпендикулярных плоскостях и Z-образная с двумя гибами 60° в одной плоскости. Утолщённые торцы — приварные фланцы.

Формулы

Длина заготовки трубы с погибами:

$$L = \sum l_{\text{пр}} + \dfrac{\pi \cdot \sum \alpha}{180^\circ} \cdot \left(R_{\text{у}} - \dfrac{r^2}{R_{\text{у}}}\right) + \Delta_{\text{пр}},$$

где Σlпр — сумма длин прямых участков по чертежу, мм; Σα — сумма углов погибов, град; Rу — радиус гиба по оси, мм; \(r = (d_{\text{н}} - t)/2\) — радиус нейтральной линии сечения, мм (dн — наружный диаметр, t — толщина стенки); \(\Delta_{\text{пр}} = 50\) мм — технологический припуск.

Показатели качества гиба:

\(E = (r/R_{\text{у}}) \cdot 100\) % — утонение стенки;   \(t_{\min} = (1 - \gamma) \cdot t/(1 + \gamma)\), где \(\gamma = r/R_{\text{у}}\);

\(k_{\text{г}} = (h/d_{\text{н}}) \cdot 100\) % — относительная высота гофров (h — высота гофра);

\(k_{\text{о}} = ((a_0 - b_0)/d_{\text{н}}) \cdot 100\) % — овальность (a₀, b₀ — большая и малая оси сечения).

Изгибающий момент при гибке: \(M = 4 \cdot (1 - \gamma^2) \cdot (0{,}97 + 1{,}09\,\gamma) \cdot \sigma_{\text{в}} \cdot r^2 \cdot t\), где σв — предел прочности материала трубы.

Скорость нажимного ролика при гибке с ТВЧ:

$$V_2 = V_1 \cdot k_0, \qquad k_0 = \dfrac{L + (R_{\text{н}} + r_0) \cdot \sin\alpha}{R_{\text{н}} \cdot \cos^2\alpha},$$

где V₁ — скорость осевой подачи трубы; L — расстояние от индуктора до ролика; \(R_{\text{н}} = R_{\text{у}} + d_{\text{н}}/2\) — радиус по наружной образующей; r₀ — радиус ролика; α — текущий угол изгиба.

Норма времени: \(\text{Т}_{\text{н}} = \sum \text{Т}_{\text{шк}\,i}\) — сумма штучно-калькуляционного времени 12 операций (отрезка, зачистка, шаблон, гибка, нагрев ТВЧ, подготовка концов, приварка фланцев, зачистка швов, подрезка фланцев, гидроиспытания, маркировка, взвешивание).

Решение по шагам

  1. Радиус нейтральной линии. r = (d_н − t)/2 = (180 − 7)/2 = 86,5 мм
  2. Длины заготовок (поправка дуги: R_у − r²/R_у = 500 − 86,5²/500 = 485,0 мм). L₁ = 1700 + 50 = 1750 мм — прямая L₂ = 1700 + 700 + (π·90/180)·485,0 + 50 = 3211 мм — один гиб 90° L₃ = 1700 + 400 + 450 + (π·180/180)·485,0 + 50 = 4123 мм — два гиба 90° L₄ = 1700 + 400 + 700 + (π·120/180)·485,0 + 50 = 3865 мм — два гиба 60°
  3. Проверка качества гиба. утонение: E = (86,5/500)·100 = 17,3 % γ = 86,5/500 = 0,173 ≈ 0,2 → t_min = (1 − 0,2)·7/(1 + 0,2) = 4,93 мм гофры: k_г = (6/180)·100 = 3,33 % ≤ 5 % — допустимо овальность: k_о = (187 − 176)/180·100 = 6,11 % ≤ 8–12 % — допустимо
  4. Пружинение. По графику для \(\alpha = 90^\circ\) угол пружинения 3,2°, для \(\alpha_1 = 60^\circ\) — 2,6°: требуемые углы перегиба: 90 + 3,2 = 93,2°; 60 + 2,6 = 62,6°
  5. Режим гибки с ТВЧ (сталь 12Х1: нагрев 850–960 °C, конец гибки не ниже 700 °C; нормализация 950–980 °C, выдержка 14–21 мин). скорость вращения гибочного рычага: v = 0,5 об/мин (по d_н = 180 мм) осевая подача V₁ = 1,45 мм/с; время нагрева зоны τ = 9 с R_н = 500 + 180/2 = 590 мм; L = 430 мм (при R_у/d_н = 2,8) при α = 45°, r₀ = 85 мм: k₀ = 2,51 → V₂ = 1,45·2,51 = 3,65 мм/с Станок — «Кюрвинг» (18,4 кВт); дорн шарообразный: \(d_{\text{вн}} = 180 - 2 \cdot 7 = 166\) мм, цилиндрическая часть 250–350 мм, зазор 1,0–1,5 мм, опережение \(0{,}28\,d_{\text{вн}}\).
  6. Масса заготовок партии из 10 труб (погонная масса трубы Ø180×7 — 29,87 кг/м). М₁ = 10·1,750·29,87 = 523 кг; М₂ = 10·3,211·29,87 = 959 кг М₃ = 10·4,123·29,87 = 1232 кг; М₄ = 10·3,865·29,87 = 1154 кг Q = 523 + 959 + 1232 + 1154 = 3868 кг
  7. Нормы времени на партию 10 труб (по операциям — таблица ниже). труба 1.1: Т_н = 1,45 ч → партия 14,5 ч труба 1.2: Т_н = 2,85 ч → партия 28,5 ч трубы 1.3 и 1.4: Т_н = 3,65 ч → партия 36,5 ч каждая

Вывод

Для трубы Ø180×7 из стали 12Х1 назначена гибка с нагревом ТВЧ на станке «Кюрвинг» с шарообразным дорном: радиус 500 мм даёт утонение 17,3 % и овальность 6,1 % — в пределах допусков. Партия из 40 труб (по 10 каждого типа) требует 3868 кг заготовок и 116 нормо-часов, причём гиб с нагревом — самая дорогая операция: каждая погибь добавляет к норме больше часа.
