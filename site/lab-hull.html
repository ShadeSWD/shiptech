Формирование корпуса судна на построечном месте

Блочный метод постройки: как разбить корпус на секции, чтобы их поднимал кран, и сколько нормо-часов уйдёт на сборку и стыковку блоков. Сквозной пример: универсальное сухогрузное судно DW 3200/4500 т, L×B×H = 100×15,3×8,3 м, кран построечного места Qкр = 80 т (вариант 16).

Цель работы

Разработать технологию формирования корпуса на построечном месте: определить погонную массу днищевой, бортовых и палубной секций, найти предельную длину секции по грузоподъёмности крана, рассчитать трудоёмкость и продолжительность установки и стыкования сборочных единиц, построить территориальный график формирования корпуса.

Теория вопроса

Корпус современного судна формируют не «россыпью» из листов, а из заранее собранных в цехе секций (плоских и объёмных) и блоков — колец корпуса, состыкованных из закладной днищевой, двух бортовых и палубной секций. Чем крупнее сборочные единицы, тем меньше работ на открытом построечном месте и короче стапельный период — но тем тяжелее подъёмы. Поэтому первый ограничитель разбивки — грузоподъёмность крана: масса секции не должна превышать Qкр.

Масса секции складывается из обшивки (полотнища), продольных связей (киль, стрингеры, карлингсы), продольного профильного набора (полособульбы) и поперечного набора (флоры, шпангоуты, бимсы, рамные железы). Удобная характеристика — погонная масса qпс: масса одного метра длины «кольца» корпуса. Разделив грузоподъёмность крана на погонную массу, получаем предельную длину секции, которую затем округляют вниз до размера, кратного шпации и раскрою листов.

Вторая часть задачи — экономика: по нормативам определяется трудоёмкость установки, проверки, стыкования и сварки каждой сборочной единицы, из неё — продолжительность операций в сменах, а из последовательности операций — территориальный график: где и когда на построечном месте стоит каждый блок.

Конструктивный мидель-шпангоут: закладная днищевая секция с двойным дном (вертикальный киль, два стрингера, полособульбы, флоры), бортовые секции с рамными шпангоутами-таврами и палубная секция с бимсами и карлингсами. Блок корпуса стыкуется из этих четырёх секций.

Формулы

Масса секции на длине одной шпации:

qпсш = qпр.об.ш + (γ·ΣSпр.св + Σqн)·lш + Σqпн [кг],

где qпр.об.ш — масса листов обшивки (полотнища) на длине шпации, кг; γ = 7850 кг/м³ — плотность стали; ΣSпр.св — суммарная площадь поперечного сечения продольных связей (киль, стрингеры, карлингсы), м²; Σqн — суммарная масса 1 м длины профилей продольного набора (полособульбов), кг/м; lш — длина шпации, м; Σqпн — масса деталей поперечного набора (флоры, шпангоуты, бимсы, рамные железы), приходящаяся на одну шпацию, кг.

Погонная масса секции (на 1 м длины корпуса):

qпс = qпсш / lш [кг/м].

Предельная длина секции по крану:

lmaxсек = Qкр / (qпсд + qпсб + qпсп) [м],

где Qкр — грузоподъёмность крана, кг; qпсд, qпсб, qпсп — погонные массы днищевой, бортовой (суммарно двух бортов) и палубной секций, кг/м.

Трудоёмкость установки и стыкования сборочной единицы:

Ti = kс·kу·(Tу + Tп + Tст + Tпн) [нормо-ч],

где kс = 1,07 — коэффициент сложности конструкции; kу = 1,0 — коэффициент условий выполнения работ; Tу — время установки; Tп — время проверки положения; Tст — время стыкования с ранее установленной секцией (блоком); Tпн — время приварки насыщения; для закладной секции слагаемые Tст и Tпн отсутствуют.

Продолжительность операции:

Пi = Ti / (α·p·t) [смен],

где α = 1,03…1,10 — коэффициент перевыполнения нормы (принято 1,05); p — число сборщиков (2–4 для секций, 4–6 для блоков); t = 8 ч — длительность смены.

Решение по шагам

  1. Погонные массы секций. q_псд = 2172,3 / 0,8 = 2715,4 кг/м q_псб = 1846,6 / 0,8 = 2308,2 кг/м q_псп = 115,78 / 0,8 = 144,7 кг/м
  2. Суммарная погонная масса кольца корпуса. q_пс = 2715,4 + 2308,2 + 144,7 = 5168,3 кг/м
  3. Предельная длина секции по крану 80 т. l_max = Q_кр / q_пс = 80 000 / 5168,3 = 15,48 м → принято l = 15,2 м Длина 15,2 м кратна раскрою листов 2×8 м и шпации 0,8 м (19 шпаций).
  4. Трудоёмкость установки секций при сборке одного блока (kс = 1,07; kу = 1,0). Т_зс = 1,07·1,0·(15 + 9,5) = 26,22 ч — закладная днищевая Т_бс = 1,07·1,0·(13,3 + 8,7 + 6,23 + 10,07) = 40,98 ч — бортовая (каждая из двух) Т_пс = 1,07·1,0·(6,7 + 4,3 + 5,78 + 10,07) = 28,73 ч — палубная
  5. Суммарная трудоёмкость сборки блока из четырёх секций. Т_блок = 26,22 + 2·40,98 + 28,73 = 136,91 ч
  6. Стыковка блоков на построечном месте. Т_зб = 1,07·1,0·(29 + 19,5) = 51,90 ч — установка закладного блока Т_стб = 1,07·1,0·(29 + 19,5 + 19,03 + 14,4) = 87,66 ч — пристыковка блока Т_сумм = 51,9 + 2·87,66 = 227,2 ч
  7. Продолжительность операций (α = 1,05; t = 8 ч). П_зс = 26,22 / (1,05·2·8) = 1,56 смены П_бс = 40,98 / (1,05·4·8) = 1,22 смены П_пс = 28,73 / (1,05·4·8) = 0,86 смены П_зб = 51,90 / (1,05·4·8) = 1,54 смены П_стб = 87,66 / (1,05·6·8) = 1,74 смены
Примечание об опечатке в первоисточнике. В исходном отчёте для палубной секции записано Тпс = 57,44 ч, однако подстановка табличных слагаемых даёт 1,07·(6,7 + 4,3 + 5,78 + 10,07) = 28,73 ч. Выше приведены исправленные значения; из-за этой опечатки в отчёте также завышены Тблок (165,62 вместо 136,91 ч) и Ппс (1,71 вместо 0,86 смены).

Свой вариант (пересчёт)

Подставьте свои погонные массы и кран — цепочки пересчитаются сразу. По умолчанию — числа разобранного варианта 16, поэтому при загрузке панель воспроизводит результаты отчёта. Нормативы трудоёмкости — в статическом разборе выше.

Вывод

Корпус судна 100×15,3×8,3 м формируется блочным методом из колец длиной 15,2 м (около 7 блоков по длине корпуса): кран 80 т ограничивает длину секции величиной 15,48 м. Сборка одного блока из четырёх секций требует ≈137 нормо-часов (≈5,5 смен работ звеньев по 2–4 сборщика), пристыковка очередного блока — ещё ≈88 нормо-часов. Эти числа — основа территориального графика формирования корпуса.
