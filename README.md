# shiptech — Технология судостроения

Статический учебный сайт (чистые HTML/CSS/JS, без сборки): производственный
цикл постройки судна — от плазовой разбивки и раскроя листа до спуска на
воду, с выводом формул и разборами на реальных числах.

**Прод:** https://shadeswd.duckdns.org/shiptech/

## О сайте

Технология судостроения отвечает на вопрос «как физически построить судно».
Сайт состоит из трёх слоёв:

1. **Курс теории** — семь глав по ходу производства, от корпусной стали до
   сдаточных испытаний: выводы формул, схемы к каждому смысловому пункту,
   числовые примеры, таблицы и контрольные вопросы.
2. **Разборы задач** — семь страниц `p-*.html`, связанных одним сквозным
   примером: скуловая секция СК-6 сухогруза 100 × 15,3 × 8,3 м, которую
   ведут от плаза до спуска. Результат каждого разбора становится исходными
   данными следующего. Каждый разбор построен одинаково: дано → шаги с
   подстановкой чисел → ответ → что это значит для цеха → что изменится при
   других данных → вопросы для самопроверки → источники.
3. **Практикум** — восемь лабораторных работ по методикам кафедры технологии
   судостроения СПбГМТУ с живым пересчётом под свой вариант.

## Содержание

- `site/` — сам сайт (без сборки, чистые HTML/CSS/JS)
  - `index.html` — обзор производственного цикла и навигация
  - `theory.html` — оглавление теоретического курса
  - `t-materials.html` — гл. 1: корпусные стали и категории РМРС, испытания
    свойств, сортамент листа и профиля, входной контроль, припуски
  - `t-plaz.html` — гл. 2: теоретический чертёж, масштабный и математический
    плаз, растяжка обшивки, развёртка поверхностей двоякой кривизны, шаблоны
  - `t-cutting.html` — гл. 3: правка, разметка, тепловая и механическая резка,
    обработка кромок, гибка листа и профиля, пружинение, припуски
  - `t-assembly.html` — гл. 4: членение корпуса, базирование, постели и
    оснастка, сварочные деформации, поточные линии, контроль геометрии
  - `t-hull-build.html` — гл. 5: построечные места, методы формирования
    корпуса, опорные устройства и нагрузки, монтажные стыки
  - `t-launch.html` — гл. 6: продольный и поперечный спуск, спуск всплытием
    и через передаточный док, достройка, центровка валопровода
  - `t-quality.html` — гл. 7: цепочки точности, индексы пригодности,
    неразрушающий контроль, испытания, организация производства
  - `tasks.html` — оглавление разборов и схема связей сквозного примера
  - `p-plaz.html` — разбор 1: длина обвода по участкам, цена спрямления скулы
    хордами, необходимое число точек, увязка чертежа, растяжка на четыре пояса
  - `p-nesting.html` — разбор 2: от чистового размера к размеру детали, три
    карты раскроя, ширина реза, коэффициент использования металла и баланс
    металла по секции
  - `p-weld.html` — разбор 3: погонная энергия, поперечная усадка и припуск на
    неё, усадочная сила и продольное укорочение, погибь таврового узла и
    обратный выгиб, угловая деформация пояска
  - `p-bend.html` — разбор 4: усилие вальцовки скулового пояса, пружинение и
    настроечный радиус, тепловая правка нагревом треугольниками
  - `p-tol.html` — разбор 5: цепочка из шести звеньев, метод максимума-минимума
    против вероятностного, вклад звеньев, индексы пригодности, припуск на стыке
  - `p-cycle.html` — разбор 6: трудоёмкость по видам работ, длительность цикла,
    потребное число постов и загрузка, эффект укрупнения; многокритериальный
    выбор способа сборки секции
  - `p-launch.html` — разбор 7: спусковые кривые численно, момент всплытия
    кормы, давление на носовые стрелы, требуемая длина подводной части
    дорожек; многокритериальный выбор способа спуска
  - `unfold.html` — развёртка листов двоякой кривизны по геодезической линии
  - `bending.html` — технологический процесс гибки листа наружной обшивки
  - `workshop.html` — пропускная способность сборочно-сварочных площадей:
    пять позиций площадки, живая циклограмма, планировка пролёта 80 × 22 м
  - `lab-hull.html` — формирование корпуса: разбивка на секции и блоки под
    кран 80 т, трудоёмкость сборки
  - `lab-berth.html` — опорно-транспортное устройство: 41 опора под сухогруз
    L = 185,6 м массой 5450 т
  - `lab-dock.html` — накат на передаточный плавучий док: 8 положений
  - `lab-pipes.html` — обработка труб Ø180×7 из стали 12Х1
  - `lab-insul.html` — теплоизоляция переборки
  - `sources.html` — источники: методические указания кафедры, учебники,
    стандарты, происхождение формул разборов и статус каждого числа
  - `assets/`
    - `base.css` — общая база кластера (мастер в `cluster-infra/www/`)
    - `style.css` — стиль сайта поверх базы
    - `shell.js` — общий каркас страниц кластера (мастер в `cluster-infra/www/`)
    - `site.js` — данные шапки, навигации и подвала
    - `tech.js` — **расчётное ядро разборов задач**: чистые функции без DOM,
      с самопроверкой `TECH.selftest()`. Все формулы `p-*.html` живут здесь
    - `calc.js`, `calc-tech.js` — живой пересчёт лабораторных работ
- `deploy/` — docker-compose (nginx:alpine, 127.0.0.1:8065) + конфиг nginx
- `tests/` — тесты (pytest)

## Сквозной пример разборов

Судно: универсальный сухогруз дедвейтом 3200/4500 т, L × B × H =
100,0 × 15,3 × 8,3 м, шпация 0,8 м, сталь категории A (σ_т = 235 МПа).
Секция СК-6: скуловая объёмная, шп. 40…49, длина 7,20 м, обвод наружной
обшивки 7606 мм (плоское днище, скула R = 1,5 м, вертикальный борт),
обшивка 10 мм, масса 9,5 т.

Контрольные числа: обвод 7,60619 м → 4 пояса по 1901,5 мм; КИМ карты раскроя
0,861 без добора и 0,922 с добором; погонная энергия автомата под флюсом
2387 Дж/мм, усадочная сила 408,8 кН, поперечная усадка полотнища 2,742 мм;
погибь таврового узла 3,46 мм на 7,2 м; усилие вальцовки 423 кН, настроечный
радиус 981 мм, 17 нагревов-клиньев; накопленная погрешность 10,5 мм по
максимуму-минимуму и 5,72 мм вероятностно; трудоёмкость 636,5 н·ч, цикл
17,1 смены; всплытие кормы на 82,2 м пути, полное всплытие на 98,07 м,
давление на носовые стрелы 1,46 МПа.

## Запуск локально

```bash
cd deploy && docker compose up -d   # проект называется shiptech (name: обязателен!)
```

Сайт поднимается на 127.0.0.1:8065; наружу отдаётся через nginx хоста
(location /shiptech/ в site duckdns). Каталог `site/` смонтирован внутрь
контейнера, поэтому правки видны сразу без пересборки.

## Тесты

```bash
python3 -m pytest tests/
```

Два набора:

- `tests/test_site.py` — переносимый набор структурных тестов кластера:
  каждая HTML-страница проверяется на корректный разбор, отсутствие дублей id
  и целостность локальных ссылок и ассетов (с учётом clean-URL nginx
  `try_files $uri $uri.html $uri/`), каждый JS — на синтаксис через
  `node --check`.
- `tests/test_tech.py` — проверка расчётного ядра `site/assets/tech.js`
  тремя независимыми способами: встроенная самопроверка модуля, пересчёт
  ключевых формул заново на Python и сверка чисел, напечатанных на страницах
  разборов, с тем, что выдаёт модуль. Опечатка в числе на странице роняет
  тест.

Тот же прогон крутится в GitLab CI (`.gitlab-ci.yml`).
