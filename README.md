# shiptech — Технология судостроения: разборы лабораторных

Статический учебный сайт (чистые HTML/CSS/JS, без сборки): производственный
цикл постройки судна разобран на сквозных примерах с реальными числами —
от разбивки корпуса на секции до спуска на воду.

**Прод:** https://shadeswd.duckdns.org/shiptech/

## О сайте
Технология судостроения отвечает на вопрос «как физически построить судно».
Восемь работ по методикам кафедры технологии судостроения СПбГМТУ
разобраны по единой схеме: цель работы → место операции в постройке → схема →
все формулы с расшифровкой обозначений → решение по шагам («формула =
подстановка чисел = результат»). Найденные в исходных отчётах арифметические
опечатки отмечены примечаниями с исправленными значениями.

## Содержание
- `site/` — сам сайт (без сборки, чистые HTML/CSS/JS)
  - `index.html` — обзор производственного цикла и навигация
  - `unfold.html` — развёртка листов двоякой кривизны по геодезической линии:
    смещения Δ точек геодезической, растяжки, стрелка выгиба по формуле
    Челнокова, проверка диагоналями; живые схемы проекции корпус и развёртки
  - `bending.html` — гибка листа наружной обшивки: стрелки погиби h и H,
    выбор контрольной оснастки и способа гибки, усилия вальцов, пресса и
    МГПС, таблицы m/K₁, свойств сталей, опор и допусков формы
  - `workshop.html` — пропускная способность сборочно-сварочных площадей:
    продолжительности по позициям, опережения, живая циклограмма (Ганта),
    планировка пролёта 80×22 м производственными площадками
  - `lab-hull.html` — формирование корпуса: погонная масса секций, предел по
    крану 80 т, трудоёмкость сборки блоков
  - `lab-berth.html` — опорно-транспортное устройство: 41 опора под сухогруз
    L=185,6 м массой 5450 т, эпюра масс, реакции, деревянные подушки
  - `lab-dock.html` — накат на передаточный плавучий док: 8 положений наката
    судна 10 000 т, реакции опор, откачка балласта
  - `lab-pipes.html` — обработка труб: труба Ø180×7 из стали 12Х1, заготовки,
    гибка с ТВЧ, дорн, нормы времени
  - `lab-insul.html` — теплоизоляция переборки: толщина 30 мм из стекловолокна,
    раскрой, трудоёмкость
  - `sources.html` — источники (лабораторный практикум СПбГМТУ и учебники)
  - `assets/` — `style.css`, `site.js`, `calc.js` (живой пересчёт пяти
    лабораторных), `calc-tech.js` (развёртка, гибка, пропускная способность:
    расчёты + генерация SVG)
- `deploy/` — docker-compose (nginx:alpine, 127.0.0.1:8065) + конфиг nginx
- `tests/` — тесты целостности сайта (pytest)

## Запуск локально
```bash
cd deploy && docker compose up -d   # проект называется shiptech (name: обязателен!)
```
Сайт поднимается на 127.0.0.1:8065; наружу отдаётся через nginx хоста
(location /shiptech/ в site duckdns).

## Тесты
```bash
python3 -m pytest tests/
```
Переносимый набор структурных тестов: каждая HTML-страница проверяется на
корректный разбор, отсутствие дублей id и целостность локальных ссылок/ассетов
(с учётом clean-URL nginx `try_files $uri $uri.html $uri/`), каждый JS —
на синтаксис через `node --check`. Тот же прогон крутится в GitLab CI
(`.gitlab-ci.yml`).
